# Deep Learning from Scratch, 2026

A 5-week, 20 hrs/week rebuild of deep learning fundamentals, from backprop to a GPT and
training-efficiency measurements.

**Main sources:** Aurélien Géron, *Hands-On Machine Learning with Scikit-Learn and PyTorch*
(O'Reilly, 2025), and Andrej Karpathy's *Neural Networks: Zero to Hero*. All code here is
written by me; where I followed a video line by line, the week's README says so.
